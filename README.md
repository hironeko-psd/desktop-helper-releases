# DesktopHelper

Windows 桌面工具的正式版本与更新文件。

支持 Windows 10 / Windows 11，64 位系统。

## 下载与安装

[前往最新版下载页面](https://github.com/hironeko-psd/desktop-helper-releases/releases/latest)

首次使用只需下载名称为 `DesktopHelper-版本号-Setup.exe` 的安装程序，双击安装即可。运行所需组件已包含在安装程序中。

其他更新附件由程序处理，无需手动下载或解压。使用说明可在程序内的“使用帮助”中查看。

## 更新

在程序内点击“检查更新”，按提示下载和应用。更新会保留本机设置和记录。

## 仓库内容

本仓库仅提供发行制品和使用说明，不包含项目源码。GitHub 自动显示的 “Source code” 下载项只对应本仓库的说明文件。
