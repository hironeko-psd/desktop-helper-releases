# DesktopHelper

Windows 10 / Windows 11 64 位桌面工具的正式版本与更新文件。

## 获取版本

[前往最新版发行页](https://github.com/hironeko-psd/desktop-helper-releases/releases/latest)

检查更新和下载公开附件不需要 GitHub 账号。首次使用可下载 `DesktopHelper-版本号-Setup.exe` 安装，运行组件已包含；已安装用户优先使用程序内“检查更新”。其他更新附件由程序处理，无需手动解压。

安装包目前没有 Windows 发行者 Authenticode 签名；应用更新使用内置 Ed25519 公钥验证，并检查更新包大小与 SHA-256。

## 1.0.7 更新内容

以下为本版定稿说明，当前可下载版本以最新正式发行页为准。

- 改善长屏和短屏队伍页识别，改用底部面板定位，避免完整成员栏因整屏比例变化被过滤。
- 修复长屏上下边缘的地图标记和聊天气泡被过滤的问题；修复合法去除底部黑边或 4:1 长屏时的新消息提示漏识别，保留原有模板匹配要求。
- 裁剪区域变化时立即停止沿用旧坐标的返回动作并重置策略；诊断补充实际画面宽高。
- 对聊天姓名识别采用有限的局部复核，扩展检查漏字情形；不把真实不同姓名模糊合并。队长不一致时显示两侧实际识别结果。同行候选同样遵守彩色徽章保护，不绕过身份检查。
- 加快动作前的画面复核，保持原有时限、判定阈值和安全检查；状态说明区分真实识别耗时与人为等待，不把调短等待时间说成能消除 OCR 耗时。
- 未知画面时说明已有识别证据；返回失败时区分未找到返回按钮、已经发送但尚未确认，不把发送输入等同于操作成功。
- 校准入口统一为“识别区域校准”，说明 DPI、完整画面区域与裁剪要求，不猜测缺失区域中的点击位置。
- 更新失败分别说明证书、HTTP、超时、磁盘空间、文件占用、权限和签名/文件损坏问题；完善下载中断、关闭取消及重复操作处理。下载阶段关闭会取消；安装已交接后保持更新保护，不把关闭窗口当作撤销已交接安装。
- HTTPS 下载仅在证书签发者错误 20/21 时尝试 Windows 原生验证；其他证书错误不能借此绕过检查。更新签名、包大小、SHA-256、版本与运行环境校验全部保留。

队伍页、地图与坐标映射已检查多组比例、宽度、裁剪及奇数尺寸，地图覆盖到 4:1。这不代表所有实际 Android DPI 重排与游戏界面均已实测；无法确认时仍会停止或等待，不强行动作。

## 应用内更新与 TLS 故障

1.0.7 使用新补丁号，为已安装 1.0.6 的用户提供应用内更新。下载和校验完成后暂停任务，再应用更新，设置和申请历史保留。

旧版本若已因 TLS 证书验证失败而无法获取清单或更新包，新清单本身不能把 TLS 补丁安装进旧版。为此准备了仅用于 1.0.6 → 1.0.7 的小型过渡更新工具；最终验收后由喵喵单独转发，用户需要接收并启动一次。它不等于旧版“检查更新”按钮已自动恢复，也不要求 GitHub 账号或完整安装包。升级后，新版程序内更新保留原生 TLS 兼容、证书验证、更新签名和失败回滚。过渡工具不作为第六个发行附件上传。

## 连接和诊断

首次使用先打开 MuMu 和游戏，再在助手设置中检测并选择所需设备。设备需要开启并允许 ADB 调试连接。检测采用 ADB 已登记设备和 MuMu 官方实例信息，不扫描局域网或任意未知服务，连接后不会自动开始申请。

诊断文字尽力脱敏，游戏截图不会自动脱敏；分享前请检查玩家名字和聊天内容。输入已发送不等于游戏已经接受申请，结果以游戏反馈及申请记录为准。
