# DesktopHelper

Windows 10 / Windows 11 64 位桌面工具的正式版本与更新文件。

## 下载与安装

[前往最新版下载页面](https://github.com/hironeko-psd/desktop-helper-releases/releases/latest)

首次使用下载 `DesktopHelper-版本号-Setup.exe` 并安装，运行组件已包含在安装程序中。其他更新附件由程序处理，无需手动解压；使用说明可在程序内查看。安装包目前没有 Windows 发行者 Authenticode 签名，应用更新包使用内置 Ed25519 公钥验证。

## 1.0.6 更新内容

- 慢 OCR 返回后，在发送动作前复核最新画面；坐标过期或画面变化时拦截，避免继续使用已失效的位置。
- 分别记录实际发送的动作、被拦截的动作和原因，帮助定位“已识别但未执行”的情况。输入已发送不等于游戏已经接受申请。
- GPU 识别失败时回退 CPU；CPU 内存分配出现致命错误时停止并反馈，避免继续重复失败或使用旧坐标。释放资源后请明确重试。
- 连接失败或设备暂时离线时保留选定目标，不静默连接其他模拟器实例；连接成功不会自动开始申请。
- 加强诊断文字的设备、路径与已知玩家信息脱敏。游戏截图不会自动脱敏，分享前请检查玩家名字和聊天内容。

## 更新和连接

已使用兼容运行环境的 1.0.5 用户可在程序内“检查更新”，按提示下载并校验，暂停任务后应用。需要完整安装时，退出助手后运行新安装包，在原位置覆盖即可，无需先卸载，设置和记录保留。旧运行环境按程序提示使用完整安装包。

首次使用先打开 MuMu 和游戏，再在助手设置中检测并选择所需设备。设备需要开启并允许 ADB 调试连接。检测采用 ADB 已登记设备和 MuMu 官方实例信息，不扫描局域网或任意未知服务。

助手退出后 ADB 后台服务可能仍在运行。安装器会核对三个私有 ADB 组件的 SHA-256：内容完全相同则保留；缺失、不同或不可读时仍按正常流程安装，不跳过必需更新。需要替换的文件被占用时，请按提示处理后重试，不要忽略错误。
