# DesktopHelper

Windows 桌面工具的正式版本与更新文件。

支持 Windows 10 / Windows 11，64 位系统。

## 下载与安装

[前往最新版下载页面](https://github.com/hironeko-psd/desktop-helper-releases/releases/latest)

首次使用只需下载名称为 `DesktopHelper-版本号-Setup.exe` 的安装程序，双击安装即可。运行所需组件已包含在安装程序中。

其他更新附件由程序处理，无需手动下载或解压。使用说明可在程序内的“使用帮助”中查看。

## 更新

在程序内点击“检查更新”，按提示下载和应用。更新会保留本机设置和记录。

## 1.0.5 更新内容

- 内置官方 Android ADB 和所需依赖，无需另行寻找 ADB 程序；修复本机 ADB 服务尚未启动时，已运行的 MuMu 仍无法被发现或连接的问题。
- 修复设置页中文路径缺字，将测试连接与关闭按钮固定在底部，避免滚动区域裁切操作按钮。
- 改进新版 MuMu 的设备与实际端口识别，列出可发现的安卓设备供选择，默认优先 MuMu。
- 优化慢启动和多开检测：先查询已登记设备，为连接与状态复核保留时间，优先已保存实例，避免旧就绪状态被继续使用；未就绪时自动重试，并区分超时、离线与等待授权。
- 适配低分辨率配高缩放的主窗口、设置和帮助布局，保留主要操作入口。
- 连接按钮显示检测进度，失败提示保留在设置窗口；不再将 16384 预填为实际端口。
- 修复高缩放屏幕上的正文模糊与任务栏图标，界面按 Windows DPI 绘制，并适配导航、按钮及弹窗布局；恢复顶部导航开关并同步帮助页版本号。

检测采用 ADB 已登记的设备和 MuMu 官方实例信息，不扫描局域网或任意未知服务。设备需要开启并允许 ADB 调试连接。

1.0.4 正式版用户可在程序内“检查更新”。本次安装器修订仍为 1.0.5，助手程序内容与上一份可靠性修订相同；已经成功安装该修订的用户无需为此再次安装。需要首次安装或覆盖安装时，请下载本页最新正式安装包。更早的 1.0.5（包括正式版或本地测试版）请先退出助手再覆盖安装；同版本不会通过版本号检查自动替换。无需卸载，设置和记录会保留。

助手退出后，ADB 后台服务可能仍在运行。本次安装器修订会先核对三个 ADB 组件的 SHA-256：内容完全相同时保留原文件，不因这些文件要求关闭后台服务；缺失或内容不同时仍正常安装或替换，不跳过必需更新。若确实需要更换的组件仍被占用，安装器会保留正常占用提示；不要直接忽略错误，应解除占用后重试。
